# 🚗 CAR RENTING WEB DESIGN

A modern and responsive **Car Renting Website** designed using **HTML, CSS, and JavaScript**. This project provides a simple and user-friendly interface for browsing and exploring rental cars.

## 📌 Project Description

The **Car Renting Web Design** project is a frontend web application created to demonstrate the design and development of a car rental website.

Users can view available cars, explore car information, and interact with different sections of the website through a clean and responsive interface.

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Interactivity and dynamic functionality

## 📄 Files and Folders

### `index.html`

Contains the main structure of the website, including navigation, car listings, rental sections, and footer.

### `css/style.css`

Contains all the styling for the website, including layout, colors, fonts, buttons, cards, animations, and responsive design.

### `js/script.js`

Contains JavaScript code used to add interactive functionality to the website.

### `images/`

Contains car images and other visual assets used in the website.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

You can also use **VS Code + Live Server** to run the project.
